# Протоколист планёрок — Telegram-бот (учебный проект VC-200, лаба 3.2)

Голосовые и текстовые сообщения планёрки → локальная расшифровка (Whisper) →
протокол и поручения (Claude API или локальная модель Ollama) → проверка кодом →
протокол .docx, планы работ .xlsx, личный план каждому участнику в Telegram.

Все люди и данные — вымышленный учебный ТОО «Степной НПЗ».

## Как устроено

```
Telegram ──► bot.py ──► service.py ──► asr.py      (голос → текст, локально, faster-whisper)
                                   ├─► llm.py      (стенограмма → JSON по schema.py; правила — prompt_protocol.txt)
                                   ├─► verify.py   (проверка без ИИ: цитата есть в тексте? срок? ответственный?)
                                   └─► render.py   (docx, xlsx, личные сообщения)
```

| Файл | Что менять без программиста |
|---|---|
| `prompt_protocol.txt` | правила, по которым ИИ пишет протокол |
| `participants.json` | участники, как их называют вслух, словарь обозначений оборудования |
| `.env` | токен бота, ключ Claude, модель, кто имеет доступ |

## Запуск

1. Python 3.11–3.13 (python.org; на Windows при установке отметить «Add to PATH»).
2. Токен бота: Telegram → @BotFather → `/newbot`.
3. Ключ Claude API: console.anthropic.com → API Keys (оплата за запросы, это не подписка Claude Pro).
   Без ключа: `LLM_BACKEND=ollama` и адрес сервера Ollama.
4. Windows: двойной щелчок `start_windows.bat`. macOS/Linux: `./start_mac_linux.sh`.
   Первый запуск создаёт `.env` — впишите токен и ключ, запустите снова.
5. Первое голосовое скачает модель распознавания (small ≈ 0,5 ГБ), дальше без интернета.

Репетиция без Telegram и без ключа: в `.env` поставить `LLM_BACKEND=fixture`, затем
`start_windows.bat rehearsal` (или `./start_mac_linux.sh rehearsal`).

Для планёрки втроём (лектор, слушатель, бот) нужна группа в Telegram: добавить бота в группу и
у @BotFather выполнить `/setprivacy` → Disable, иначе бот в группе не видит обычные сообщения.

## Команды бота

`/new [ДД.ММ.ГГГГ] [название]`, `/status`, `/undo`, `/protocol`, `/iam Фамилия`, `/cancel`.
Реплику, начатую с фамилии («Ахметов. Пальцы придут завтра»), бот записывает за этим участником.

## Тесты

```
.venv/bin/python -m pytest -q tests      # Windows: .venv\Scripts\python -m pytest -q tests
```
Тесты идут без интернета: модель подменена эталонным ответом, Telegram — подставными объектами.
