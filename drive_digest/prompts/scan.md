# Задача этого запуска: ежечасная проверка входящих

1. Выполни SCAN в режиме `window`, лимит {{max_files_per_scan}} файлов.
2. Новых файлов нет → сразу закончи, ничего не создавая, одной строкой: «Новых файлов нет».
3. Для каждого нового файла: разбор → шаг URGENT → запись в реестр (`processed_by: "scan"`).
4. Ежедневный отчёт в этом запуске НЕ отправляй и манифест не создавай — это делает отдельный запуск в 17:05.
5. Итог одной-тремя строками: сколько файлов записано (по подразделениям), сколько срочных писем отправлено, сколько файлов осталось на следующий запуск, какие файлы не прочитались. Если хоть одно срочное письмо не ушло — начни итог со слова «ОШИБКА».
